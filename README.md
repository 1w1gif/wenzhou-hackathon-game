# 《衍月·八相》

> 温州黑客松 2026 · AI+游戏赛道 · 主题「平行时空」

她是可以回到过去的女侠，却救不下最亲近的人。

中秋满月之夜，强盗攻塔，青梅竹马沈砚死在衍月面前。她得到「月相轮」——一件能让时间倒流八格月相的古仪，但每次回溯，都要燃烧她自己的生命，而沈砚会彻底忘记她。

即使他不记得我，我也要救他。

## 玩法

- **2D 横版动作探索**：跑跳、二段跳、碰墙自动吸附攀墙、蹬墙跳
- **女侠战斗**：三段连击、剑气、闪身，斩退强盗劫匪（化墨消散）
- **剑技解谜**：剑既是武器也是钥匙——斩绳、击钟、压重、点灯
- **潜行 / 强攻**：部分关卡二选一，潜行有额外奖励
- **时间循环**：月相轮每次回溯转过一格月相，代价是生命值，机关与路线随循环改变
- **结局分歧**：失忆的沈砚会被古仪侵蚀成反派拦住去路——信任值与「是否对他拔剑」决定四个结局（团圆 / 以命换命 / 剑锋相向 / 生命耗尽）

## 美术

中国传统水墨风格：宣纸底色、墨色晕染、月光留白。古风角色剪影，敌人化墨，回溯时墨迹晕染转场。
