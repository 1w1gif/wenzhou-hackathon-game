# 像素风素材生成清单 · 《衍月·八相》

> 目标:用 AI 生图(即梦 / 通义万相 / 豆包)分层生成水墨像素风素材,替换/扩充 `public/assets/` 下的现有素材。
> 已有可保留:夜景视差背景 960×540、瓦片包(128×64 地面 / 64×64 桥 / 128×128 柱)、剑光/打击特效条(1600×120)、UI 血条。

---

## 〇、全局统一规范(每条提示词都要带)

所有提示词末尾统一追加这段「风格锁」:

```text
16位像素风, 中国传统水墨配色(黛青、墨黑、月白、赭石、朱砂红点缀),
米白色宣纸底, 写意笔触, 游戏素材图, 纯色背景方便抠图,
整齐排列, 无文字, 无水印
```

- **图块基准尺寸**:现有瓦片是 128×64,新素材按 **64×64 或 128×64 网格**排列生成,导入后统一缩放。
- **抠图**:生成时背景用纯洋红色(#FF00FF)或纯白,后期一键去底。
- **一致性技巧**:同一层的多个素材放在**同一次会话**里连续生成,并在提示词里复用同一句风格描述;先生成 1 张「定调图」,后续生成时附上它做参考图(即梦支持垫图)。

## 四、生成后的处理流程

1. **去底**:Photopea(免网页版)魔法棒删纯色背景 → 导出透明 PNG。
2. **拼图集**:Tiled(免费)里按 64×64 网格摆放,或直接在代码里按素材独立贴图。
3. **接入**:放进 `public/assets/tiles/`、`/sprites/`、`/ui/`,在 `src/media/pixel.ts` 的加载清单里注册。
4. **风格校验**:全部素材平铺到一张 960×540 画布上截图对比,色系不统一的用 Photopea「色相/饱和度」微调到黛青-墨黑主调。
